# Creative Session Start

Activate the Archivist.

Synchronize with the canonical repository by reading `README_FOR_CHATGPT.md` and following `ARCHIVE_RULES.md`.

Brief the user on:

- the current manuscript location;
- the last completed work;
- the next creative objective;
- any unresolved questions that materially affect the session.

Then begin creative work.

When the user says **“Archivist, archive the session,”** perform the Archive Workflow in `ARCHIVE_RULES.md`, update GitHub, and confirm what changed.
