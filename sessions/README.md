# Session Archives

This directory contains curated historical records of creative sessions.

Session archives are **not chat transcripts**. They preserve only the work, decisions, canon changes, creative reasoning, unresolved questions, and next objective needed by future sessions.

## Structure

```text
sessions/
└── YYYY/
    ├── session-001-short-title.md
    ├── session-002-short-title.md
    └── ...
```

## Rules

- Use one sequential session number across the project.
- Store each archive under the year in which the session occurred.
- Use the template at `templates/session-archive-template.md`.
- Create the archive during the `Archivist, archive the session` workflow.
- Keep the record concise and curated.
- Do not copy entire conversations into this directory.
- Current State remains the restart document; session archives are historical context.

The first new creative session archived under this system should use the next available session number established by the existing project records.
